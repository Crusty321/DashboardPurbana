Arquitectura de Módulos (Diagrama de Escalera)

1. Inicio de Sesión
  • Diseño e implementación de la base de datos de usuarios (credenciales y permisos).
  • Desarrollo de interfaz de formulario seguro para autenticación (Login).
  • Configuración de sesiones y tokens de seguridad básicos.
2. Asignación de Roles
  • Definición de lógica para Encargado (Admin) con permisos de escritura/carga.
  • Definición de lógica para Personal (User) con permisos de solo lectura.
  • Creación de middleware para protección de rutas según el rol.
3. Gestión Documental
  • Habilitación de servidor local para almacenamiento estructurado de archivos físicos.
  • Desarrollo del componente de carga (Upload) con restricciones de formato (PDF, Word).
  • Creación de listado interactivo con botones de búsqueda y descarga rápida.
4. Avisos y Novedades
  • Diseño del Muro Principal (Feed) interactivo en la pantalla de inicio de los usuarios.
  • Implementación de base de datos para almacenar comunicados, fechas y autores.
  • Ajustes de UI/UX para resaltar avisos de alta prioridad (urgentes).
5. Módulo Publicador
  • Desarrollo del panel de administración restringido (exclusivo para rol Encargado).
  • Creación de formulario avanzado (WYSIWYG) para redacción de nuevas publicaciones.
  • Lógica de edición, eliminación temporal y publicación en el muro general.
